# Atividade EaD - Programação Web

**Qual é a função do HTML na página desenvolvida?**
O HTML organiza o conteúdo da página: o título, os textos, a imagem, as listas e os botões.

**Onde você utilizou CSS e quais alterações ele realizou?**
Usei no arquivo style.css. Ele mudou a cor de fundo, as cores e tamanhos dos textos, deixou os botões mais bonitos e arredondou as bordas da imagem.

**Onde você utilizou JavaScript e o que acontece quando ele é executado?**
Usei no arquivo script.js. Quando clico nos botões, ele mostra a descrição das habilidades, mostra ou esconde as curiosidades, troca o texto e muda a cor da caixa.

**Qual é a principal diferença entre CSS e JavaScript?**
O CSS cuida da aparência da página, e o JavaScript faz a página reagir quando o usuário clica.
